# 火叶闪光音效实验参考

用户于 2026-10-03 提供两份 WAV，均为 0.772 秒、48kHz、双声道、16位 PCM。

- `shiny-effect-original.wav`：保留背景音乐和原始音量，实验主参考。
- `shiny-effect-enhanced.wav`：背景抑制试验，供试听和检测分数对照；并非完全纯净的原始闪光音效。

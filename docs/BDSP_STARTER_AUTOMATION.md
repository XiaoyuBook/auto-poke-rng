# 珍钻复刻御三家全自动

自动流程页选择草苗龟、小火猴或波加曼，在“基础脚本”组开启“御三家全自动”。
该模式不需要选择测种、过帧、撞帧或反查脚本。关闭此选项后恢复原有自选脚本模式，
原脚本和可选功能配置保留。已有配置不会被自动切换。

眼睛模板、ROI、源分辨率和关闭菜单 +1 沿用选择的眨眼配置。运行时自动采用用户截图
提供的时序，不改写保存的眨眼配置：

| 参数 | 值 |
| --- | ---: |
| Threshold | 0.7 |
| Time Delay | 0 |
| Advance Delay | 41 |
| Advance Delay 2 | 48 |
| NPCs | 1 |
| NPCs during Timeline | -1 |
| Pokemon NPCs | 2 |

## 执行顺序

1. 从测种脚本开始：运行内置 `seed.ecs`，复用已有共享帧眨眼捕获与 Seed 求解。
   也可从当前游戏起点直接捕获 Seed；本模式不提供从已过场 Seed 校正开始。
2. 锁定目标后接管：复用放大模式两次确认、双 HOME、退出复查；确认
   “怎么回事？刚才那两人……”并逐页按 A。只对稳定的真实对白正文按 A，
   录像中只有省略号的页面也会推进。
3. 停在“就是想还也不知道对方是谁啊，虽然有听到叫博士……”；
   到目标 RNG 帧减 **200** 时自动请求 Timeline。200 是代码常量。
4. 沿用 Project_Xs 第一段倒计时，在 Timer 从 1 变成 0 时立即按 A。
   推进遭遇对话，停在“搞什么啊！”。
5. 第二段同样在 Timer 从 1 变成 0（第 10 个 Timeline 事件）时立即按 A，
   随后推进至“要选哪一只？”。下一事件的 48 Adv 补偿沿用 Project_Xs 原时序。
6. 到目标 RNG 帧减**本轮实际 delay**时开始选择；按物种向右移动 0 / 1 / 2 次，
   按 A 打开确认，向上选“是”，再按 A。整组动作由常驻手柄进程连续执行：
   每个按键按住 30ms（固件最短报告间隔），按键之间不添加菜单或导航等待。
7. 复用现有“去吧/上吧”→“战斗”判闪；出闪按原规则录像并停止，结果未知停止。
   未出闪运行内置 `reverse.ecs`、OCR 反查、保存 delay 样本，再按循环设置处理。

delay 使用现有策略，每轮开始读取并固定一次。反查样本仅影响后续轮次，
不临时改写已锁定目标的 delay。测种和反查 ECS 原文及许可来源见
`resources/automation/bdsp-starter/README.md`。

## 时序约束与停止

两段倒计时和转换消耗的计数为 `11 × (1 + 1) + 41 + 11 + 48 = 122` Adv。
因此此预设要求实际 delay **小于 78**，还需要给精灵球过场留出时间。
软件不会将 200 拉大或截断 delay：固定策略在启动检查时报错，动态策略在每轮
固定实际值时检查。旧撞帧脚本的 delay 样本未必适用于新的快速选择动作，
应使用该动作对应的御三家 delay。

选择阶段已去掉原有的确认菜单 1800ms、向右后 120ms 和向上后 100ms 等待，
按键保持时间从 100ms 缩短为 30ms。使用这组连续选择动作时需重新校准 delay；
此前较慢动作的反查样本不能代表当前时序。

对话确认与时钟运行分离。OCR 在后台识别实际白色对话正文，计时线程按共享的
Project_Xs RNG 时钟调度；它不依赖 React 状态刷新或 OCR 完成时间触发倒计时按键。
两段 A 都使用计数首次归零的时间戳，Adv 补偿按原版后续节点计算。归零后处理过晚
会记为错过目标，避免用更晚的切换或补偿节点补按 A。
错过启动、倒计时或选择节点时不选择精灵，本轮记录“错过目标”，按已配置循环
继续或结束。对话、视频源、OCR 或手柄故障明确停止；停止释放控制动作。

## 动效语义

- 当前节点：约 1.8 秒一个呼吸周期，圆心缓慢明暗变化、轻微缩放；外圈淡淡扩散消失。保持节点标签清晰稳定。全图只有真实当前业务阶段持续呼吸。
- 已确定的下一节点：亮色空心圆，稳定显示。当前到下一节点的线显示方向光点和渐隐短拖尾。
- 状态变化由真实事件驱动；光点到达的视觉动画不能自行宣布后端已进入下一阶段。动画时长只控制表现，不能驱动业务状态。
- 下一阶段尚不确定时不得根据模拟顺序猜测或同时点亮多个分支。可在真实转移发生后短暂播放刚走过的边；有明确已选择决策时再显示预计下一节点。
- 旧节点离开后停止呼吸，新节点接管。已停止、失败、正常完成时停止运行光效，保留最后位置和明确结束原因；收尾与已结束不能混淆。
- 遵守减少动态效果偏好，组件卸载时清理动画/监听；不要在每次帧数刷新时重建整张图或重启呼吸周期。

## 连线与真实状态映射

至少正确体现以下分支，方向按真实活动决定，不以绘制顺序当状态机：

- 测种 → 搜索；搜索 → 过帧；搜索 → 等待。
- 过帧 → 校正；过帧 → 重新测种（受策略和当前场景规则约束）。
- 校正 → 再次过帧；校正 → 搜索；**校正 → 等待**。
- 等待 → 撞帧判闪 → 结果处理，以及实际运行需要的重试、目标错过、同轮逃跑续搜和下一轮。

用户最后特意纠正了“校正 → 等待”直达边，必须保留。当前 runner 在 REIDENTIFY 后，已有锁定目标时进入 DECIDE_ADVANCE，再按距离与策略选择等待、过帧等；没有锁定目标才回 SEARCH_TARGET。内部决策不应被展示成一次重新搜索，也不能为了图形布局强迫经过搜索节点。

普通位置校正与最终启动时机校准应区分。FINAL_CALIBRATE / FINAL_WAIT / FINAL_ADJUST 可作为等待触发组内具体活动显示，REIDENTIFY 才是位置校正节点。撞帧脚本和判闪可能并行，不能伪造先后完成。

可选过场、反查、录像等按真实配置与实际事件显示具体子状态，保持主卡片紧凑；例如反查/录像属于结果处理的活动说明。涉及回流时反映实际去向，不用装饰性外围大圈，也不虚构不存在的直达动作。

同轮补救、重新测种或逃跑续搜不自动增加循环轮数，本轮 delay 保持锁定。只有真实新轮次事件才更新轮次。完成不等于出闪，判闪未知不等于确定未出闪。
